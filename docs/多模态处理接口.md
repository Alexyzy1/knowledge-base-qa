
# 多模态处理接口

服务地址：通过环境变量 `ASR_BASE_URL` 配置

---

## POST /video_chat

上传视频文件，提取视频图像描述和音频文字，合并返回。

**并发限制**

| 层级 | 信号量 | 值 |
|------|--------|----|
| API 入口 | `video_chat_semaphore` | **1**（串行） |

> 视频图像转文字和音频转文字并发执行（`asyncio.gather`），`only_extract_audio=true` 时跳过图像处理。

**请求（multipart/form-data）**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `video_file` | file | 是 | — | 视频文件二进制内容 |
| `video_name` | string | 是 | — | 文件名（含扩展名，用于判断格式） |
| `only_extract_audio` | bool | 否 | false | `true` 时仅提取音频，跳过视频图像识别 |

**支持的视频格式**

`mp4`, `avi`, `mov`, `mkv`, `flv`, `wmv`, `webm`, `mpeg`, `mpg`, `3gp`, `m4v`

**返回（200）**

`only_extract_audio=false`（默认）：

```json
{
  "video_name": "example.mp4",
  "video_text": "视频 example.mp4 的主要内容如下：\n# 视频图像内容：\n<图像描述>\n# 视频音频内容：\n<音频转写>"
}
```

`only_extract_audio=true`：

```json
{
  "video_name": "example.mp4",
  "video_text": "视频 example.mp4 的主要内容如下：\n# 音频内容：\n<音频转写>"
}
```

**错误返回**

```json
{"error": "10301/10302", "message": "...", "status": "0", "result": "执行失败"}
```

## POST /audio_chat

上传音频文件，返回音频转写文本。

**并发限制**

| 层级 | 信号量 | 值 |
|------|--------|----|
| API 入口 | `audio_chat_semaphore` | **1**（串行） |

**请求（multipart/form-data）**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `audio_file` | file | 是 | 音频文件二进制内容 |
| `audio_name` | string | 是 | 文件名（含扩展名，用于判断格式） |

**支持的音频格式**

`aac`, `amr`, `avi`, `flac`, `flv`, `m4a`, `mkv`, `mov`, `mp3`, `mp4`, `mpeg`, `ogg`, `opus`, `wav`, `webm`, `wma`, `wmv`

**返回（200）**

```json
{
  "audio_name": "example.mp3",
  "audio_text": "音频 example.mp3 的主要内容如下：\n# 音频内容：\n<音频转写>"
}
```

**错误返回**

```json
{"error": "10301/10302", "message": "...", "status": "0", "result": "执行失败"}
```
