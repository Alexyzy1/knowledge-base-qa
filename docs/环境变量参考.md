# yuanzy 项目环境变量参考

## 服务基础

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `MODEL_API_BASE` | `https://api.deepseek.com/v1` | LLM/Embedding API 地址 |
| `MODEL_API_KEY` | (空) | LLM/Embedding API Key（**生产必设**） |
| `MYSQL_URL` | `mysql+pymysql://kb_user:kb_pass@127.0.0.1:3306/knowledge_base?charset=utf8mb4` | 数据库连接（**生产必设**） |
| `MILVUS_URI` | `http://localhost:19530` | Milvus 连接地址 |
| `JWT_SECRET` | (自动生成) | JWT 签名密钥，设置后容器重建不丢失 |

## 模型选择

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `LLM_MODEL` | `DeepSeek-V4-Flash-H800` | 问答/改写用的 LLM |
| `EMBEDDING_MODEL` | `Qwen3-Embedding-4B` | 向量化模型 |

## Token / 性能上限

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `LLM_ANSWER_MAX_TOKENS` | `1024` | 问答回答 token 上限 |
| `QUERY_REWRITE_MAX_TOKENS` | `256` | 检索改写 token 上限 |
| `RERANK_MAX_TOKENS_CAP` | `2048` | Rerank 打分 token 上限 |
| `RERANK_MAX_RETRIES` | `2` | Rerank 失败重试次数 |

## 查询增强 Feature Flags

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `ENHANCE_ENABLED` | `true` | 查询增强总开关 |
| `HYDE_ENABLED` | `true` | HyDE 生成假设答案 |
| `MULTI_QUERY_ENABLED` | `true` | 多查询改写 |
| `ENHANCE_CLASSIFIER_ENABLED` | `true` | 查询分类器 |

## 安全

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `SAFETY_LLM_CHECK` | `false` | 词库未命中时是否过 LLM 审查 |
| `IP_ACCESS_ENABLED` | `false` | 是否启用 IP 白名单 |
| `IP_ACCESS_ALLOWED` | (空) | 白名单 IP，逗号分隔 |
| `RL_TRUSTED_PROXY` | (空) | 信任的代理 IP（读 `X-Forwarded-For`） |

## 限流

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `RATE_LIMIT_WINDOW` | `60` | 限流窗口秒数 |
| `RL_IP_CHAT` | `60` | `/api/chat` 每窗口 IP 限制 |
| `RL_IP_LOGIN` | `10` | `/api/auth/login` 每窗口 IP 限制 |
| `RL_IP_REGISTER` | `5` | `/api/auth/register` 每窗口 IP 限制 |
| `RL_IP_DEFAULT` | `120` | 其他接口每窗口 IP 默认限制 |
| `RL_USER_CHAT` | `30` | 已登录用户聊天每窗口限制 |
| `RL_WHITELIST_IPS` | (空) | 不限流的 IP，逗号分隔 |

## ASR 引擎

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `ASR_ENGINE` | `legacy` | `legacy` 或 `qwen` |
| `QWEN_ASR_MODEL` | `Qwen3-ASR-1.7B` | ASR 模型名 |
| `QWEN_ASR_BASE_URL` | `MODEL_API_BASE` 的值去掉 `/v1` | Qwen ASR 地址 |
| `QWEN_ASR_API_KEY` | `MODEL_API_KEY` 的值 | Qwen ASR API Key |
| `QWEN_ASR_TIMEOUT` | `120` | 单次 ASR 请求超时秒数 |

## ASR 长音频切分

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `QWEN_ASR_FFMPEG_PATH` | `ffmpeg` | ffmpeg 二进制路径或文件名 |
| `QWEN_ASR_FFPROBE_PATH` | `ffprobe` | ffprobe 二进制路径或文件名 |
| `QWEN_ASR_SPLIT_THRESHOLD` | `60` | 超过此秒数触发切分 |
| `QWEN_ASR_MIN_SEGMENT` | `15` | 最短段长（秒） |
| `QWEN_ASR_MAX_SEGMENT` | `60` | 最长段长（秒） |
| `QWEN_ASR_SILENCE_DB` | `-40` | 静音判定的分贝阈值 |
| `QWEN_ASR_SILENCE_DURATION` | `0.5` | 多长停顿算静音（秒） |
| `QWEN_ASR_MAX_CONCURRENT` | `3` | 最大并发 API 请求数 |

## 生产启动命令示例

```bash
cd backend && nohup env \
  ASR_ENGINE=qwen \
  MODEL_API_KEY="sk-..." \
  MYSQL_URL="mysql+pymysql://root:password@127.0.0.1:3306/knowledge_base?charset=utf8mb4" \
  IP_ACCESS_ENABLED=true \
  python -m uvicorn main:app --host 0.0.0.0 --port 8000 > /tmp/uvicorn.log 2>&1 &
```
